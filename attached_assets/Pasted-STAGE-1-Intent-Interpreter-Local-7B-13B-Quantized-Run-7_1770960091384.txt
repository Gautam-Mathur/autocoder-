7B or 13B 4-bit via llama.cpp

Structured output enforced via schema

No deep psychological modeling.

Use structured prompts.

Cache recurring user archetypes in vector DB.

This becomes a pattern recognizer, not a philosopher.

Local LLM → draft MVP + roadmap

Rule engine → detect SaaS patterns

Vector DB → competitor memory

No large reasoning loops.
Instead: iterative passes with memory injection.

STAGE 3 — Constraint Analyzer (Deterministic Engine)

Do NOT waste LLM tokens.

This stage becomes:

Rule-based system

Config-driven matrix

Predefined engineering templates

Zero need for heavy model inference.

STAGE 4 — Semantic Domain Modeler (Structured Graph Builder)

Instead of "ontology hallucination":

Extract entities via LLM

Build graph via deterministic parser

Store in:

SQLite

Or lightweight Neo4j

Graph reasoning becomes algorithmic, not model-based.

Instead:

Maintain architecture pattern library

Score against constraints

Choose pattern deterministically

LLM only explains choice.

Engineering decisions move from generative → evaluative.
